# Proposed public GitHub issue

Destination: https://github.com/RyotaUshio/obsidian-pdf-plus/issues/new

Title: Request for permission to list an independently maintained PDF++ continuation

Hello Ryota,

Thank you for creating PDF++. I maintain an independent continuation based on PDF++ 0.40.31:
https://github.com/minLaoGe/obsidian-pdf-plus-sync

The continuation adds vault-file reading progress and bookmarks, inline FreeText editing, colored text and area highlights with batch saving, and undo/redo for these editing workflows. Your original code, MIT license, and attribution are preserved. It is clearly described as an independent project, not an official release from you.

I would like to submit this continuation to the Obsidian Community directory. The current developer policies require publicly verifiable approval from the original author, or the documented inactive-maintainer process:
https://docs.obsidian.md/community-directory/developer-policies

Would you explicitly approve listing this continuation under its own plugin ID (`pdf-plus-sync`) and the name PDF++ Sync? The listing would credit you, link to the original project, and explain that the original PDF++ must be disabled when using this continuation.

If you would prefer another attribution, name, or coordination approach, please let me know. This request is specifically about listing the continuation; it does not request ownership or control of your repository or existing community entry.

Thank you for considering this request.
